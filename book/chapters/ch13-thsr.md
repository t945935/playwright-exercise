# 第 13 章　高鐵班次查詢：板橋到台南，取得完整查詢結果

高鐵官網的結果頁可能每頁顯示有限班次，卻把完整資料放在頁面資料或分頁中。本章的重點是「完整取得」，不是只讀取第一頁看到的五班。

## 13.1　執行指定查詢

```bash
.venv/bin/python examples/03_data_queries/thsr_banqiao_tainan.py
.venv/bin/python examples/03_data_queries/thsr_banqiao_tainan.py --date 2026-09-18 --start 09:00 --end 11:00 --headed
```

預設條件是板橋到台南、09:00–11:00。輸出放在 `outputs/transport/thsr/`，同時提供 CSV 和 JSON。輸出內保留查詢日期與站點，方便和臺鐵結果區分。

## 13.2　讀取完整資料

E08 會檢查頁面提供的 `timetableData`，再以出發時間篩選。畫面每頁顯示五班不代表只有五班；若只用 `locator(".result-row")` 讀當前 DOM，可能漏掉分頁內容。完整資料解析後，再將欄位轉成讀者看得懂的格式。

抵達時間使用班次的 `DestinationTime`，不要從停靠站清單中再次搜尋台南站的出發時間。兩者在中途停靠情境下可能不同，誤用會讓抵達時間錯誤。

## 13.3　驗證結果數量

查詢成功後至少檢查：回應沒有錯誤、資料陣列存在、每筆有車次和時間、時間落在指定範圍。若資料陣列為空，要判斷是當日沒有班次還是站點選擇失敗。列表分頁和完整資料數量不一致時，先停止寫檔並保留頁面內容。

## 13.4　比較兩種交通查詢

臺鐵和高鐵都需要日期、站點和時間，但網站元件不同。不要把一個網站的 CSS 選擇器複製到另一個網站；可共用的是資料模型、時間驗證、輸出格式和錯誤分類。這就是把通用邏輯與網站特定操作分開的好處。

## 13.5　練習

1. 指定一個沒有直達班次的時段，檢查程式的空結果處理。
2. 將 JSON 中的每筆班次加上查詢條件摘要。
3. 以 `--headed` 觀察官網分頁，對照輸出筆數，確認程式沒有只讀第一頁。
