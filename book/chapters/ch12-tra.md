# 第 12 章　臺鐵班次查詢：彰化到嘉義，匯出 CSV 與 JSON

本章使用臺鐵官方時刻表查詢彰化到嘉義、08:00–10:00 的直達班次。程式只查詢，不訂票；有班次也不代表仍有座位。

## 12.1　把條件保存進結果

執行：

```bash
.venv/bin/python examples/03_data_queries/tra_changhua_chiayi.py
.venv/bin/python examples/03_data_queries/tra_changhua_chiayi.py --date 2026-09-18 --start 08:00 --end 10:00 --headed
```

查詢日期、出發站、抵達站和時段應和每筆班次一起寫入 JSON；CSV 也應有表頭，讓讀者開啟檔案時知道條件。預設輸出在 `outputs/transport/tra/`，可用 `--output-dir` 指定其他位置。

## 12.2　表單與結果

程式依序選日期、站點、車種和時間，提交後等待結果表格。它使用官方頁面目前的選項文字，而不是把下拉選單的內部數字寫死。結果列讀取車次、車種、出發與抵達時間、行駛時間、經由路線、票價和詳情連結。

如果站點名稱或時間選項改變，應先在有畫面的 `--headed` 模式觀察頁面，再更新定位器。查詢錯誤、空結果和成功結果分開處理；失敗時盡量保存 `.error.html`。

## 12.3　時間範圍的意義

08:00–10:00 指從彰化出發的時間，不是抵達嘉義的時間。程式先將命令列字串驗證為 `HH:MM`，再套用官網可選的半小時選項。若使用 `23:59` 代表當天最後時間，需在指南中明確說明。

## 12.4　不要把查詢變成訂票

選取班次或票種只為顯示票價與詳情，不應點擊訂票、登入或付款按鈕。書籍案例使用唯讀查詢；若日後加入訂票流程，必須另寫權限、確認和取消設計，不能悄悄延伸現有範例。

## 12.5　練習

1. 查詢明天同一時段，確認輸出檔名包含日期。
2. 將站點改成另一組城市，檢查 JSON 中的查詢條件是否同步變更。
3. 以一個沒有班次的時段測試，確認報告顯示空結果而不是查詢失敗。
