# 附錄 E　讀者服務、問題回報與書籍勘誤

讀者服務入口是 [GitHub 儲存庫](https://github.com/t945935/playwright-exercise)。首頁提供下載、安裝、範例索引和更新紀錄；Issues 提供「範例執行問題」與「書籍勘誤」表單。

回報範例問題時，請提供：

1. 範例檔名或 E 編號。
2. 從專案根目錄執行的完整命令。
3. 作業系統、Python 和 Playwright 版本。
4. 查詢日期、預期結果、實際結果和完整錯誤文字。

不要貼上登入 Cookie、Token、密碼、私人後台網址或含個人資料的截圖。若問題只在真實網站發生，請說明網站名稱和公開頁面，不必提供帳號資訊。

書籍初稿會隨讀者試跑修訂。更新後請查看 `CHANGELOG.md`；若你保存了舊版程式，先確認版本再比較差異。網站改版、交通班次、新聞和行情變化都可能造成不同結果，回報時附上日期能幫助判斷是程式錯誤還是資料變動。

這本書目前以 Markdown 保存，日後轉成 EPUB 或 PDF 前會再檢查程式碼、連結、圖表和版面。讀者回報的勘誤會先在 GitHub 討論，再更新章稿與版本紀錄。
