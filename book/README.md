# 書籍編寫工作區

暫定書名：**Python × Playwright 做中學**  
副標題：從安裝到新聞、交通、股價與網站自動化的 16 個實作

對象為 Python 與瀏覽器自動化初學者。預估 220–280 頁，實際頁數待兩章試寫後調整。現階段已完成專案分類，既有程式為實作原型，正文尚未開始。

| 文件／目錄 | 用途 |

| [outline.md](outline.md) | 四篇、18 章規劃與範例對應 |
| [progress.md](progress.md) | 編寫階段、章節狀態與出版前待辦 |
| [templates/chapter-template.md](templates/chapter-template.md) | 每章共用格式 |
| [chapters/](chapters/) | 正式 Markdown 章稿 |
| [assets/](assets/) | 經整理的書籍插圖與圖表 |
| [../docs/example-index.md](../docs/example-index.md) | 16 個範例的正式檔案與指南 |

建議先試寫第 3 章「第一支程式」及第 10 章「新書雷達」，確認教學深度、圖文比例與執行步驟，再擴展其他章節。程式以 `examples/` 為唯一教學來源，章稿引用關鍵片段，避免另存整份程式造成版本分歧。
